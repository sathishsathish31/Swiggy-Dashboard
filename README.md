# Swiggy Order Analysis Dashboard | Power BI Project

Welcome to my Power BI dashboard project based on **Swiggy order data**!  
This project showcases my skills in data analysis, visualization, and storytelling with real-world food delivery data.

## 🔍 Project Overview

In this dashboard, I explored key insights from Swiggy orders, including:
- 🕒 **Order trends** over time  
- 💳 **Payment method usage**  
- 📦 **Order status breakdown**  
- 💰 **Revenue analysis**  
- 🏆 **Top restaurants and customers**

## 📊 Tools & Techniques Used
- Power BI  
- Data Cleaning & Transformation  
- DAX Measures  
- Visual Design Principles

## ✨ Key Features
- Interactive filters for date, status, and more  
- Dynamic charts and KPIs  
- Clean and user-friendly layout
